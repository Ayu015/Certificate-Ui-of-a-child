# Certificate of Merit UI

A web-based **Certificate of Merit** design created using HTML and CSS. The project represents a school achievement certificate awarded to students for their participation and performance in academic or extracurricular activities.

## 📸 Project Overview

The certificate design includes:

- Arya Vidya Mandir – Bandra West school branding
- School logo
- Certificate of Merit heading
- Student name
- Standard and division
- Award/course title
- Date of achievement
- School address
- Director and Principal details

## ✨ Features

- Clean and professional certificate layout
- School logo and branding
- Structured student information
- Decorative golden header and footer
- Blue typography for certificate content
- Print-friendly certificate design

## 🛠️ Technologies Used

- HTML5
- CSS3
